# ACM FAccT version (reframed)

`main.tex` is the FAccT-angled version of the paper: same results, reframed around accountability,
transparency, and information asymmetry, with a "Accountability implications" section
(refusal-first read-out, disclosure standard separating identity from content, and the connection
to biometric / EU AI Act regulation).

**Status:** FAccT 2027's call for papers is not yet out (venue page says "stay tuned"); the main
deadline is typically early in the year. This source is ready in advance.

**Compiling:** uses the ACM `acmart` class in anonymous review mode
(`\documentclass[sigconf,anonymous,review]{acmart}`). It compiles directly on **Overleaf**
(acmart and all dependencies are built in). A local TeX install needs `acmart` plus its
dependencies (totpages, hyperxmp, environ, etc.). Figures are shared from `../figures/`.

Do not submit the same content to FAccT and TMLR concurrently: both are archival, and TMLR's
originality rule (and FAccT's) forbid parallel archival submission. Choose one archival home.
