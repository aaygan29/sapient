# Qualia Demo — Frontend Handoff

*For the frontend engineer. Everything needed to wire the demo to a UI. The demo data is REAL,
validated, integrity-checked Mary results (not mocked). Written 2026-05-30.*

## TL;DR — what the demo shows
**"Mary perceives the world through a human brain — measured."** Mary predicts the human brain's
response to **held-out stimuli it never trained on**, across all 7 cortical networks, and
**per-person models beat the average brain ~3.7×** (that per-person signal is the data moat).

The honest line (must keep): this is **representational alignment** — real encoding accuracy of
Mary's predicted fMRI vs real fMRI — **not** a claim that the machine "feels."

## Data contract — `results.json`
```jsonc
{
  "title": str, "claim": str,
  "model": { "name":"Mary", "detail":str, "space":"fsaverage5", "vertices":20484, "channel":"improving" },
  "metric": str,                       // human-readable description of the number
  "network_order": [str x7],           // Visual..Default (render bars in this order)
  "social_networks": [str],            // subset to highlight (VentralAttention, Limbic, Frontoparietal, Default)
  "headline_personalization": { "per_subject_mean_r":float, "average_mean_r":float, "ratio":float, "beats_average":bool },
  "stimuli": {
    "<name>": {                        // "forgot" (narrative) and "bourne" (movie)
      "label":str, "dataset":str, "modality":str, "n_subjects":int,
      "noise_ceiling_overall":float,
      "per_network": [                 // one per Yeo-7 network — the bar chart
        { "network":str, "mary_r":float, "noise_ceiling":float,
          "pct_of_ceiling":float, "n_parcels":int, "is_social":bool }
      ],
      "personalization": { "per_subject_mean_r":float, "average_mean_r":float, "ratio":float, "beats_average":bool },
      "is_broadcast_artifact": bool,   // false = genuine vertex signal (good)
      "figures": { "network_bars":"assets/..png", "brain_surface":"assets/..png" }
    }
  },
  "honesty": str,        // SHOW this caption
  "provenance": str
}
```

### Suggested UI (see app.py)
- Headline card: the `headline_personalization.ratio` ("per-person beats average 3.7×").
- Stimulus toggle: `forgot` (narrative) / `bourne` (movie).
- Left: `figures.brain_surface` (Mary's predicted cortical map).
- Right: bar chart from `per_network` — `mary_r` vs `noise_ceiling`; highlight `is_social` networks.
- Always render the `honesty` caption.

## How the data is produced + how it UPGRADES (important)
- `results.json` is generated by `build_demo_data.py` from Mary's validated Paper-A results.
- Qualia loads Mary via a **registry** (`qualia/core/registry.py`) with an `improving` channel.
  **When Mary is retrained/improved, you regenerate the data and every number gets better — no UI
  change.** The brain space (20,484 fsaverage5 vertices → Yeo-7) is fixed, so the schema is stable.
- The live engine path (for new stimuli) is `qualia/demo/encode_score.py` (Modal) → `MaryEngine`.

## Honesty rules the UI MUST follow
1. Label the number "encoding r (Mary's predicted fMRI vs real fMRI)" — **representational/affective
   alignment, not feeling**.
2. Always show the **noise ceiling** next to Mary's r (never a naked number).
3. "Per-subject > average" is the personalization/moat story — feature it.
