# Pre-Registered Acceptance Criteria — Sapient v1

These criteria are committed **before any training run**. They are the ship gates for flipping `SAPIENT_SCORER=v1` in production. Editing this file after a training run completes is a violation of the pre-registration discipline; if criteria need to change, document the reason and treat the prior run as exploratory.

## Ship gates (all three must hold)

Ship `SAPIENT_SCORER=v1` to production only if **all three** of the following are true:

1. **Across-subject val (model selection)** — Mean Pearson R across DMN + MFG parcels **> 0.20** on `sub-15` and `sub-16` (the across-subject val split defined in `splits.json`).

2. **Held-out test (model card numbers)** — Mean Pearson R across DMN + MFG + TPJ + ACC parcels **> 0.15** on the held-out test subjects (`sub-17`, `sub-18`, `sub-19`, `sub-20`). The held-out test set is **touched exactly once**, after model selection on the across-subject val split is complete. If a number from this set is read more than once before sign-off, the run is invalidated.

3. **Robot-partner generalization** — Per-construct **Spearman R > 0.25** between Sapient v1's `engagement` score and the ground-truth NeuroEngage engagement label, on the robot-partner held-out subjects (`sub-19`, `sub-20`). This guards against a model that only learns human-partner patterns and confirms the central claim of the Sapient pitch: the model generalizes from neural responses to robotic interlocutors to scoring text from AI agents.

4. **Real-behavior validation gate for any aggregate parcel→score composite** (added 2026-08-25) — Before any single-number composite derived by collapsing parcel activations across ROI groups (the pattern `scripts/buy_moment/buy_moment_detector.py`'s `score_z` follows, and any future "global engagement/drive" style readout built the same way) may be used to support a behavioral claim, it must show a **documented, non-zero correlation against a real behavioral ground-truth signal** — not merely fMRI Pearson R against the training target.

   **Why this gate exists.** arXiv:2607.01400 ("A global predicted-fMRI drive signal from TRIBE does not predict YouTube replay heatmaps") shows that a TRIBE-style whole-cortex encoder's output, collapsed into an aggregate engagement/drive signal, does **not** correlate with real behavioral engagement (YouTube "most replayed" heatmaps) — pooled position-controlled partial r = +0.058, 95% CI [-0.04, 0.15], p = 0.23, below basic loudness/motion baselines — even though the same encoder hits good held-out fMRI Pearson r on its actual training objective. Encoder fit does not imply the aggregated read-out predicts behavior. Gates 1-3 above only ever check fMRI Pearson R / Spearman R against a neural or neural-derived label; none of them would catch this specific failure mode for a downstream composite score like buy-moment detection.

   **Current status of this gate (updated 2026-08-26): still BLOCKED on real ground truth, PASSING on the synthetic stand-in — now for a more precisely diagnosed reason.** Original check (2026-08-25): `sapienteval/03_parcellate.py` and `sapienteval/04_align_stimuli.py` (the NeuroEngage `ds004996` pipeline outputs) emit no usable behavioral label distinct from BOLD — `04_align_stimuli.py` aligns per-TR transcript text and BIDS `event_type` tags (`fixation_cross` / `comprehension` / `production` / `silence` / `turn_initiation`), not a scalar behavioral outcome. The "ground-truth NeuroEngage engagement label" referenced in gate 3 above is a v1 mapping-head construct not yet implemented (see `SCIENCE.md` §7).

   **Re-checked 2026-08-26 against the actual `ds004996` `participants.tsv`/`participants.json`** (fetched live from `github.com/OpenNeuroDatasets/ds004996`, not re-derived from pipeline code alone — see `SCIENCE.md` §13 for full detail): the raw dataset DOES carry `eng_level_run-1/2/3` columns (high/medium/low, mapping to the paper's EC/AL/PL conditions) not previously surfaced. This is a real correction to the prior framing. However it still does not clear this gate, for two disclosed reasons: (a) `eng_level` is an experimenter-assigned conversation condition, not a measured behavioral/self-report outcome — the dataset's own README states *"Preprocessed data and questionnaire results: to be uploaded,"* i.e. the actual self-report questionnaire data that would count as a real outcome is not yet public; and (b) even if it counted, this worktree and its Modal volumes hold no locally-accessible real parcellated BOLD for any `ds004996` subject to correlate it against — regenerating that requires a fresh multi-hour fMRIPrep run, out of scope for this session. StudyForrest and Emo-FilM were also checked as candidate real datasets with genuine behavioral-outcome channels paired with naturalistic fMRI; both are real and viable in principle for a future session with compute budget for download + parcellation, neither was pursued further here for the same compute-barrier reason.

   **Status update (2026-08-25/26) — the "future session" assumption above was re-checked directly, and a real correlation was obtained (`scripts/buy_moment/real_behavior_emofilm.py`).** StudyForrest (`ds000113`) was re-checked for real rather than assumed: individual movie-run BOLD files are actually a manageable ~65 MB each (not the ~258 GB whole-dataset figure, which is dominated by 7T structural/DTI/SWI/retinotopy/localizer data not needed here) and its annotation data is real and freely downloadable — but the functional data is only linearly aligned to a group-specific BOLD template, not MNI; reaching Schaefer-400/MNI space needs the separate nonlinear `studyforrest-data-templatetransforms` warp applied via FSL/ANTs, neither of which is installed in this environment. This is a genuine, disclosed tool/pipeline blocker (not a size blocker), so StudyForrest was not pursued further.

   **Emo-FilM (OpenNeuro `ds004892` fMRI + its companion `ds004872` annotation dataset) cleared every feasibility check.** Its `derivatives/preprocessing/.../space-MNI_desc-ppres_bold.nii.gz` files are already motion-corrected, WM/CSF-regressed, AND already coregistered to MNI by the dataset's own authors (no registration pipeline needed); its annotation companion provides real, continuous, 1 Hz human-coded emotion/engagement ratings, no DUA. For 3 subjects (S01/S02/S03, `BigBuckBunny` stimulus): Schaefer-400 parcels were extracted with the same `NiftiLabelsMasker`/`fetch_atlas_schaefer_2018` call `connectome_validation.py` uses, cropped to each subject's own real film onset/duration (`events.tsv`), resampled to 1 Hz, run through the UNMODIFIED `detect_buy_moments`, and correlated against a 4s-HRF-lagged real engagement proxy (mean of the `IntenseEmotion`/`Alert`/`Attention` annotation columns; 4s lag = the convention already used in this codebase's NeuroEngage pipeline, `SCIENCE.md` §3). Significance via a subject-blocked circular time-shift permutation null (2000 permutations) — appropriate given the strong autocorrelation in both series, the same style of null `validate_against_behavior.py` already uses.

   **Real result (n=3 subjects, 1 stimulus; full JSON in `scripts/buy_moment/real_behavior_out/emofilm_bigbuckbunny_result.json`)**:

   | Channel | pooled r | p (block-permutation, two-sided) |
   |---|---|---|
   | `score_z` (undifferentiated composite) | +0.029 | 0.660 — not significant |
   | `generalizable_score` (the aggregate-safe channel per §"Generalizable vs idiosyncratic channels" below) | +0.079 | 0.284 — not significant |
   | `idiosyncratic_score` (individual-only channel) | +0.107 | 0.077 — a trend, not significant |

   Per-subject, `idiosyncratic_score` was nominally significant uncorrected in 1 of 3 subjects (S03, r=+0.209, p=0.039) — this does not survive correcting for the 9 comparisons actually run (3 channels × 3 subjects), and is not the channel this gate's aggregate-claim framing is about.

   **This gate is now: real evidence obtained, real result is a NULL finding, still BLOCKED for any ship decision.** This is the first real (not synthetic) correlation number this gate has ever had, and it does not support treating the buy-moment composite (or specifically `generalizable_score`, the channel an aggregate/market-level claim should be checked against) as behaviorally validated — the real correlation is statistically indistinguishable from chance in this sample. This is consistent with, not a refutation of, the exact failure mode arXiv:2607.01400 motivates this gate to catch. **What this one result does NOT establish**: n=3 subjects and 1 non-purchase-relevant stimulus (an animated short, not an ad) is too small and narrow a sample to conclude the composite never tracks real behavior in general — a decisive resolution needs more Emo-FilM subjects/stimuli (the dataset has ~30 subjects × 14 movies available) and ideally replication in a second real dataset. Until then, do not ship a behavioral claim from this composite on the strength of either the earlier synthetic pass or this real-but-small-and-null result.

   Until a larger/decisive real result exists, `scripts/buy_moment/validate_against_behavior.py` still stands in as a **synthetic, disclosed** validation harness for CI-checkability: it injects a known synthetic "engagement" process into synthetic (T, 400) parcel data, runs `detect_buy_moments` on it, and permutation-tests (circular time-shift null, 1000 iterations) whether the composite's `score_z` recovers the injected signal above chance. As of this writing it **passes** (observed r ≈ +0.997, permutation p ≈ 0.001) — a pass here still means only "the detector's arithmetic is not obviously broken on a favorable synthetic case," not "the buy-moment composite is behaviorally validated." **Neither the synthetic pass nor the real-but-null Emo-FilM result above satisfies this gate for a production ship decision.**

   **To actually clear this gate for shipping a buy-moment-style composite as a behavioral claim** (updated in light of the real-but-inconclusive Emo-FilM result above), one of the following is required:
   - A real behavioral/purchase/engagement outcome channel wired into the NeuroEngage pipeline (extending `04_align_stimuli.py` or a new stage) with a documented, pre-registered correlation threshold against `score_z` (or `generalizable_score` — see the split introduced in §"Generalizable vs idiosyncratic channels" below; the aggregate-claim version of this gate should be checked against `generalizable_score`, not the undifferentiated composite, per the Genevsky & Knutson evidence cited there), or
   - An equivalent real external behavioral dataset (e.g. an actual ad-recall/purchase-intent study run against the same stimuli) correlated post hoc against the composite.

   Ship a composite parcel→score readout for a behavioral claim (buy-moment or otherwise) **only after** one of the above is done and documented here with the actual correlation value, sample size, and p-value — following the same "touched once" discipline as gate 2.

## Generalizable vs idiosyncratic channels (informational — not yet a ship gate)

`scripts/buy_moment/buy_moment_detector.py` now reports two additional channel scores alongside the original composite: `generalizable_score` (NAcc/OFC + amygdala/temporal-pole "early affective" ROI groups) and `idiosyncratic_score` (vmPFC/mPFC + DLPFC "integrative/deliberative" ROI groups). This follows Genevsky & Knutson (2018, "Neuroforecasting Aggregate Choice"; 2025, "Neuroforecasting reveals generalizable components of choice," PNAS Nexus 4(2):pgaf029), which show NAcc/ventral-striatal anticipatory-affect activity generalizes across people to predict aggregate choice (ICC ≈ 0.41-0.44, significant across two independent experiments) while mPFC integrative-value activity does not (ICC ≈ 0.20-0.27, non-significant). Any FUTURE aggregate/market-level ship claim built on the buy-moment composite should be checked against `generalizable_score`, never the undifferentiated composite or `idiosyncratic_score` — the latter is only appropriate for individual-response claims. This is not yet an enforced ship gate (no aggregate-level claim currently ships from this module) but is documented here so it becomes one the moment such a claim is proposed.

## ROI_GROUPS real-connectome grounding (informational — not a ship gate)

Added 2026-08-26 (`scripts/buy_moment/connectome_validation.py`, `SCIENCE.md` §12). All 8 `ROI_GROUPS` bundles in `buy_moment_detector.py` were checked against real fMRI connectivity from 8 adult subjects (nilearn's `fetch_development_fmri`, public naturalistic-viewing data, no DUA): every bundle's mean within-group connectivity beat all 1000 same-size random-parcel-set draws (100th percentile, observed r 0.22-0.40 vs. random-null mean r ~0.09). Separately, all 8 bundles sit at 100% purity within a single Schaefer/Yeo-7 published network label. This grounds the parcel-*bundling* choice in real connectivity data and real published atlas labels — it is **not** a behavioral validation and does **not** satisfy gate 4 above; a group being internally coherent in real connectivity data says nothing about whether its score predicts buying behavior. Treat this as informational grounding for the "not anatomically curated" caveat in `SCIENCE.md` §9, not as a new ship gate.

## Cross-market cultural-calibration hypothesis (informational — not a ship gate)

Added 2026-08-26 (`scripts/buy_moment/cultural_calibration.py`, `SCIENCE.md` §14). This is the least-evidenced layer in this directory and is explicitly a hypothesis, not a shipped capability.

**What has real (if qualitative) literature support**: the broad individualism/collectivism cultural axis, per Han & Northoff (2008, *Nat Rev Neurosci* review) and Han & Ma (2014, *NeuroImage*, a real 35-study coordinate-based meta-analysis, confirmed via WebSearch/WebFetch this session): self-referential-processing regions (vMPFC) run stronger in Western samples, social-cognition regions (dMPFC/TPJ) run stronger in East Asian samples. This covers exactly two of the eight `ROI_GROUPS` bundles: `Default_PFC_vmPFC` and `Default_Temp_SocCog`.

**2026-08-25 update — direction strengthened, magnitude still unfit (`SCIENCE.md` §16, full derivation there).** Re-read Han & Ma (2014) in full this session (the earlier paywall block is resolved): its Tables 2-4 report only ALE cluster coordinates and volumes, no Cohen's d/Hedges' g/t-value for any region — a structural property of coordinate-based ALE meta-analysis, not an oversight, so no quantitative multiplier was ever extractable from this paper. No 2023-2026 replacement meta-analysis with an extractable effect size for this exact contrast was found either. We did find, per the fallback path, a real independent primary study — Ma et al. 2014, *Soc Cogn Affect Neurosci* 9(1):73-80 (PMC3871729), 30 Chinese vs. 30 Danish participants — whose reported F-statistics convert via the standard F→d formula (t=√F, d=t·√(1/n₁+1/n₂)) to large, direction-confirming Cohen's d: mPFC self-reflection d≈1.07 (Danish>Chinese), left/right TPJ social-attribute reflection d≈0.79/0.77 (Chinese>Danish). These are real numbers from a real 60-subject study and materially strengthen confidence in the calibration's **direction**. They do NOT license a new magnitude: that study's d is a standardized effect on its own arbitrary-unit GLM parameter-estimate scale, with no shared unit to convert into this pipeline's Schaefer-parcel-activation multiplier — bridging the two would require an invented, unstated conversion assumption, which was not done. `_MULTIPLIER_STRENGTH` therefore remains unchanged at the arbitrary +/-15% placeholder.

**What does NOT have literature support, disclosed rather than assumed**:
- **Reward circuitry (NAcc/OFC/ventral striatum) cross-culturally** — no coordinate-based meta-analysis isolating this was found this session, despite an explicit search. `Limbic_OFC` (the NAcc/OFC "generalizable" proxy) is therefore left uncalibrated.
- **US vs. China specifically** — no verified peer-reviewed consumer-neuroscience fMRI study comparing these two markets (or named East Asian countries individually) was found; a 2024 neuromarketing bibliometric review names this as a known field-wide research gap. The module's `target_market` parameter is scoped to `"western"` / `"east_asian"` (the axis the literature actually distinguishes), not `"US"` / `"China"`.
- **Every other ROI_GROUPS bundle** (`Limbic_TempPole`, `Cont_PFCl_DLPFC`, `Cont_Par_CogLoad`, `SalVentAttn_FrOperIns`, `SalVentAttn_ParOper`) — no verified cross-cultural literature found; left uncalibrated.

**What the module does**: applies a small (+/-15%, an arbitrary hypothesis magnitude not derived from any effect size), directional multiplier to the two literature-supported groups only, before recomputing `generalizable_score`/`idiosyncratic_score`. `target_market="unspecified"` (the default) is a confirmed exact no-op.

**Robustness check performed**: calibration was run against synthetic (T,400) noise at all three `target_market` settings — no NaNs, no crashes, no pathological sign flips, and the no-op case verified numerically identical to the uncalibrated composite (`np.allclose`, atol=1e-5). This validates the CODE ONLY. **No behavioral validation of this calibration exists for any market** — this is a known limitation, not a shipped capability, and should not be represented to any stakeholder as a validated per-market adjustment.

## Statistical-methodology hardening (informational — not a ship gate)

Added 2026-08-26 (`scripts/buy_moment/stat_utils.py`, `connectome_validation.py`, `multivariate_fusion.py`; `SCIENCE.md` §15). Framing note carried over from `SCIENCE.md` §15: **this system is not an EEG-fMRI fusion pipeline** — no EEG signal or coregistration exists anywhere in this codebase, and generic EEG-fMRI multimodal-fusion methodology does not apply here. Four real, applicable statistical gaps were closed instead:

1. **Multiple-comparisons correction** on the 8 `ROI_GROUPS` connectome tests from the informational section above — BH-FDR (Benjamini & Hochberg 1995) and max-statistic FWER (Nichols & Holmes 2002) now reported additively alongside the original uncorrected numbers. All 8 groups remain significant after both corrections (FDR q ≤ 0.002, FWER p ≤ 0.002) — the correction did not change the verdict here because the uncorrected effect was already at the 1000-permutation floor for every group, but it is now computed and reported rather than absent.
2. **Pseudo-replication fix**: the prior pooled-average-then-null check (8 subjects averaged into one matrix before nulling) is kept for continuity but explicitly labeled as the weaker approach; a new subject-level check nulls each of the 8 subjects independently and runs a Wilcoxon signed-rank test across them. All 8 groups pass (p = 0.0039-0.0078, FDR-significant).
3. **CCA/PLS small-N stability** — Helmer et al. (2024, *Communications Biology*, verified via WebSearch) shows CCA/PLS brain-behavior weight patterns are unstable below roughly N~1000 subjects; Sapient trains on N=4-8. PLS/CCA were implemented anyway, heavily caveated: a block-bootstrap stability check and an MDES abstention gate (ported from the user's own `decision_phenotype` project) accompany every fitted weight/correlation, plus a lower-variance univariate-correlation alternative reported side by side.
4. **Fitted-vs-hand-picked weight comparison** — on synthetic data, sign agreement between the multivariate fit and the hand-picked `ROI_GROUPS` weights is perfect (8/8, expected by construction), but rank-order correlation of weight magnitude is only moderate (+0.45 PLS, +0.26 CCA) — a real, disclosed, non-conclusive validity check on the hand-picked weights.

**Provenance note**: the MDES gate, bootstrap-CI helper, and empirical-Bayes subject-shrinkage in `stat_utils.py`, and the accuracy-weighted channel-combination rule in `multivariate_fusion.py`, are ported/adapted from the user's own prior research repos (`decision_phenotype`, GitHub `aaygan29/ideal-doodle`; `behavioral_decoding`, GitHub `aaygan29/behavioral_decoding`), read in full and cited explicitly in `SCIENCE.md` §15e — not generic external methodology.

**None of this is a ship gate.** It grounds the internal statistical rigor of the buy-moment scoring layer's diagnostic modules; it does not touch gate 4 above (real-behavior validation), which remains BLOCKED exactly as before.

## Fallback policy

If **any** of the three thresholds is missed:

- **Do not** flip `SAPIENT_SCORER=v1`.
- Ship `sapient_v0.5` (the ridge linear-encoding baseline) as a documented intermediate.
- Disclose the miss honestly in the model card (`src/data/sapient_v1_model_card.ts` and `src/sapienteval/ModelCardV1.tsx`): which threshold was missed, by how much, and the candidate hypothesis for why.
- Continue iterating; do not re-test on the held-out set until the next ship attempt.

## ROI definitions (for the thresholds above)

These refer to Schaefer-400 7-Networks parcels and standard cortical labels:

- **DMN** — Default Mode Network parcels (posterior cingulate / precuneus, vmPFC, bilateral angular gyrus).
- **MFG** — Middle Frontal Gyrus parcels (DLPFC, executive control).
- **TPJ** — Temporo-Parietal Junction parcels, bilateral (mentalizing / theory of mind).
- **ACC** — Anterior Cingulate Cortex parcels (conflict monitoring, frustration, surprise).

The exact parcel-index lists are frozen in `06_train_mapping_head.py` once that script lands; the lists themselves are part of the pre-registration.

## Evaluation space (clarification — no threshold change)

All three thresholds above are **already specified in 400-parcel Schaefer space**, which matches the space we train in. This is intentional, not a relaxation: fine-tuning happens in parcel space (see `SCIENCE.md` §6 for the architectural rationale — we bypassed the base model's native 20,484-vertex fsaverage5 output to avoid a FreeSurfer mesh dependency we couldn't satisfy, and chose to compute the loss directly against our parcellated targets).

Pearson R in parcel space is a coarser signal than vertex-space R would be (one number per ~50-vertex neighborhood instead of per-vertex), but it is also a *lower-variance* signal — appropriate for an N=4 pilot where vertex-space R would be unstable due to noise. We will revisit vertex-space training at the 20-subject scale-up if the parcel-space R meets the ship thresholds.

Re-iterating, no threshold changes are needed: `> 0.20` mean R across DMN+MFG and `> 0.15` across DMN+MFG+TPJ+ACC remain the gates, computed in 400-parcel space, on the splits defined in `splits.json`.
